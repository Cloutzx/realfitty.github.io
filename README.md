# 🎮 RealFitty Website

Official RealFitty creator website featuring Twitch live status, Discord community integration, and social links.

Built with:
- HTML
- CSS
- JavaScript
- Twitch API
- Discord Widget
- Render (Backend Hosting)
- GitHub Pages (Frontend Hosting)

---

# ✨ Features

## 🔴 Twitch Live Status

- Automatically checks if RealFitty is live
- Shows:
  - Live status
  - Stream title
  - Game category
  - Viewer count
  - Twitch embedded player

Uses the Twitch Helix API.

---

## 💬 Discord Integration

Displays:

- Current Discord online members
- Discord server widget
- Community invite

---

## 🌌 Website Design

Features:

- Animated background
- Floating particles
- Cursor glow effect
- Glass UI cards
- Smooth scrolling
- Hover animations
- Responsive mobile layout
